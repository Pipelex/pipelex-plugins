# Test data

`mthds-corpus/` is a vendored copy of the whole MTHDS Test Corpus, the tagged set of `.mthds` methods every repository in the workspace draws its language-level fixtures from. It is generated by the workspace's corpus sync (`mthds-corpus-sync`, run with `--apply --consumer pipelex-plugins --into <worktree>`) and refreshed when a `pipelex` release changes the corpus. Never edit it here: an entry is authored in `pipelex`, at `pipelex/test_extras/mthds_corpus/`, where the gates that keep it meaningful run, and the sync's drift check compares this copy with the canonical one byte for byte.

`tests/unit/test_hook_corpus.py` runs the edit hook over every entry, and `docs/hooks.md` ("Checks") says what it expects of each.
